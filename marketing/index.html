How it works

Three steps, one committed JSON report.

01

Read

Finds your OpenAPI spec, scans your tests. No configuration.

02

Compare

Matches every documented response to the assertions that check it.

03

Guard

The report is one committed file. CI fails when it goes stale.

What it works with

An OpenAPI spec and a JavaScript or TypeScript test suite. Nothing to annotate, no plugin, no runner integration.

Your spec
OpenAPI 3.x and Swagger 2.0
Discovered on its own: the shallowest openapi* or swagger* file in the repo. Pass --spec when yours lives somewhere unusual.
JSON or YAML
Either format, read as-is. Both produce the same proof, so converting between them never reads as drift.
Your tests
TypeScript and JavaScript
.test.ts, .test.tsx, .test.js, .test.jsx, anywhere in the repo.
Vitest, Jest, Bun test
Any runner with describe / it and expect. The HTTP client makes no difference: SpecProof reads the assertion, not the request.
tests/tasks.test.ts The two lines it reads 
describe("POST /tasks", () => {           // the operation
  it("creates a task", async () => {
    expect(res.status).toBe(201);         // the response it proves
  });
});
Methods

GET POST PUT
PATCH DELETE

Path params

{taskId} = [taskId]
= :taskId

Assertions

.toBe(201)
.toEqual(201)

Anything outside that shape is simply not matched: a suite titled "creating tasks", or a check written assert.equal(statusCode, 201). Those responses are reported as untested rather than guessed at, so a verified verdict always has a real test behind it.

Get started

Install as a dev dependency and run it from your repo.

Terminal · npm, pnpm, yarn, or bun 
$ npm install -D specproof
$ npx specproof dev
→ localhost:3001

On CI

Commit the report next to your code.
specproof generate --check exits 1 when the report is out of date.

.github/workflows/specproof.yml 
name: specproof
on: [pull_request]

jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
      - run: npm install
      - run: npx specproof generate --out specproof.json --check
