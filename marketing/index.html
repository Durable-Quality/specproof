How it works

Three steps, one committed JSON report.

01

Read

Finds your OpenAPI spec, scans your tests. No configuration.

openapi.yaml or openapi.json POST /tasks
201Task created
400Malformed body
401Missing bearer token
tasks.test.ts .tsx .js .jsx describe("POST /tasks")
201it("creates a task")
400it("requires a title")
422it("rejects a past date")
02

Compare

Matches every documented response to its assertions.

POST /tasks
201 Verified
400 Verified
401 No test
422 Undocumented
03

Guard

The report is one committed file. CI fails when it goes stale.

What it works with

The frameworks we support, and the syntax we read.

tests/tasks.test.ts Named imports from vitest.
import { describe, it, expect } from "vitest";
describe("POST /tasks", () => {operation
it("creates a task", async () => {
expect(res.status).toBe(201);response
});
});
tests/tasks.test.ts Globals, and a supertest response instead of a fetch one.
import request from "supertest";
describe("POST /tasks", () => {operation
it("creates a task", async () => {
expect(res.status).toBe(201);response
});
});
tests/tasks.test.ts test() is read exactly like it().
import { describe, test, expect } from "bun:test";
describe("POST /tasks", () => {operation
test("creates a task", async () => {
expect(res.status).toBe(201);response
});
});
tests/tasks.test.js toEqual() is read exactly like toBe().
// describe, it and expect are globals
describe("POST /tasks", () => {operation
it("creates a task", async () => {
expect(res.status).toEqual(201);response
});
});

Get started

Install as a dev dependency and run it from your repo.

Install
$ bun add -d specproof
$ npm install -D specproof
$ pnpm add -D specproof
$ yarn add -D specproof
Run
$ bunx specproof dev
$ npx specproof dev
$ pnpm exec specproof dev
$ yarn specproof dev

Serves the report at localhost:3001. Pass --port to host it somewhere else, or --spec when your OpenAPI file lives somewhere the shallowest openapi* / swagger* lookup will not find it.

On CI

Add .github/workflows/specproof.yml and commit the report next to your code.

CI 
name: specproof
on: [pull_request]

jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
      - run: npm install
      - run: npx specproof generate --out specproof.json --check
